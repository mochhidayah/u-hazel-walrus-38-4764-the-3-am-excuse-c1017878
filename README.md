A hardware wallet refuses to sign a transaction at 3 AM — in one line under
200 characters. `main.ts` holds a shelf of excuses invented for this bounty,
grades each against the judge's own published brief (on-subject, original
angle, the wallet's voice, the hour as the joke, tight wording), and writes
the winner to `/output/entry.txt`.

## The winning line (141 characters)

> 3 AM. I am the only thing in this house still awake, and I am a metal box with no bed. I am not signing this — I am signing you up for sleep.

## Run

```sh
node main.ts
cat /output/entry.txt
```
